# Связь MyElement с tt-stat

В таблице «Ваши видео» откройте меню ⋮ → «Извлечь JS».

- Если для видео уже сохранён JS, откроется его версия из MongoDB.
- Если версии нет, открывается локальный шаблон tt-stat-cc. Он также включён в клиент, поэтому код можно редактировать и скачивать при недоступном API. Сохранение в MongoDB доступно после успешного подключения API.
- «Актуальный JS с сайта» повторно получает опубликованный скрипт. Чтобы закрепить его за текущим видео, нажмите «Сохранить для видео».
- «Загрузить новый JS» читает выбранный файл в редактор. Сохранение выполняется отдельно.
- Код можно редактировать, копировать и скачать как `app-<videoId>.js`.
- «Предпросмотр» отображает JS редактора на HTML/CSS из tt-stat-cc в изолированном iframe.

Скрипт сохраняется в коллекции MongoDB `video_scripts`. У каждого видео свой документ и номер версии. Если код уже сохранили в другом окне, сервер отклонит устаревшее сохранение: сначала загрузите сохранённую версию. При получении с сайта отображается время проверки, при сохранении — время сохранения.

При недоступности сайта можно явно открыть локальную копию из `server/data/tt-stat/app.js`. Она помечена как локальная, а не актуальная версия сайта.

Ограничение — 256 КБ исходного JS в UTF-8. Сервер проверяет синтаксис обычного браузерного скрипта (как app.js из tt-stat-cc) без выполнения. ES-модули с import/export в этом формате не поддерживаются. Предпросмотр не имеет доступа к cookie/хранилищу кабинета и API; внешние сетевые запросы JS запрещены. Изображения HTTPS и Google Fonts разрешены для исходного макета.

Из tt-stat-cc скопированы только файлы для предпросмотра:
- src/assets/tt-stat/index.html
- src/assets/tt-stat/style.css
- src/assets/tt-stat/app.js (шаблон для редактирования без API)
- server/data/tt-stat/app.js (шаблон сервера)

Файлы исходного проекта tt-stat-cc не изменяются. Сохранение в MyElement не изменяет общий сайт tt-stat.vercel.app. Для применения изменений MyElement нужно обновить клиент и сервер. Публикация не выполнялась.

Проверки:
- из корня: npm run build
- из server: node tests/video-scripts.js

Интеграционный тест читает опубликованный app.js и создаёт отдельную временную базу cdxt_<случайный идентификатор>. Он проверяет авторизацию, сохранение и чтение, версии, одновременное сохранение и изоляцию видео. В finally удаляет только две тестовые коллекции своей временной базы. Данные рабочего приложения не изменяются.
