# Выдача комментариев

В таблице «Ваши видео» нажмите «Комментарии», выберите тематику и количество (по умолчанию 250), затем «Создать страницу». Скопируйте ссылку `/get-comment/<id>` и передайте посетителям. Старые ссылки доступны в том же окне настройки видео.

Страница открывается без входа в кабинет. Создавать наборы и просматривать список ссылок могут только авторизованные пользователи.

## База данных

Используется уже настроенная MongoDB из `server/.env` (`MONGO_URI`), отдельный сервис не нужен. Коллекция `comment_pages` создаётся при создании первой страницы. Набор, остаток и выданные варианты хранятся в базе. Перезапуск сервера их не сбрасывает.

Для каждой страницы создаётся случайная выборка без повторений. Атомарная операция MongoDB одновременно убирает вариант из доступных и сохраняет выдачу: разные посетители одной страницы не получат один и тот же вариант даже при одновременном запросе. Выданные варианты сохраняются в истории для повторных запросов, но из доступного списка удаляются.

Один вариант — сочетание текста и дополнительных указаний `tags`. Одинаковый текст с разными упоминаниями/стикерами считается разными вариантами. Между разными страницами наборы независимы и могут пересекаться.

Посетитель определяется случайным идентификатором в localStorage. Повторное нажатие, обновление страницы и повтор запроса вернут тот же комментарий. Другой браузер, режим инкогнито или очистка хранилища считаются новым посетителем. Без авторизации нельзя гарантировать один вариант на физического человека.

## Источник

Из `seed_comments.txt` импортировано 308 записей, после удаления 11 полных дублей осталось 297 вариантов. Текст и указания сохранены без изменений. В файле нет изображений стикеров — интерфейс показывает указание, какой стикер нужно добавить.

После редактирования исходного файла выполните из корня:

```sh
node server/scripts/import-comments.js
```

Импорт обновляет `server/data/comment-themes.json`; затем перезапустите сервер. Уже созданные страницы сохраняют свой набор. Новые тематики можно добавить в JSON как объекты `id`, `label`, `comments` (массив `{text, tags}`). Скрипт импорта сейчас предназначен для единственной тематики rubupDropComments и перезаписывает каталог.

## Запуск

Терминал 1, из `server`: `npm run dev` (нужны установленные серверные зависимости и существующие настройки MONGO_URI/JWT_SECRET).

Терминал 2, из корня: `npm run dev`.

На Vercel добавлено перенаправление `/get-comment/:id` на index.html. Для публикации изменений нужно обновить и сервер в Render, и клиент в Vercel. Никакие изменения автоматически не публиковались.

## Проверка

Сборка из корня: `npm run build`.

Проверка конкурентной выдачи из `server`: `node tests/comment-claims.js`. Тест использует подключённую MongoDB, создаёт только отдельную временную коллекцию со случайным именем и удаляет её в finally. Проверяются параллельные выдачи, окончание набора, повторный запрос после окончания, параллельные запросы одного посетителя, сохранение tags и отсутствующая страница.
