# Проекты макетов

Из «Ваши видео»: ⋮ → Макет → Проект и параметры.

POST /api/stat-projects с videoId создаёт проект или возвращает уже существующий. Один активный проект на видео. Страница настроек: /projects/<id>. Сохранённый макет: /projects/<id>/preview. Старый адрес /tt-stat/<videoId> автоматически показывает проект этого видео, если он есть, иначе прежний JS.

В проекте четыре раздела:
- Видео и счётчики: название проекта, длительность в секундах, просмотры/лайки/комментарии/репосты/сохранения, URL обложки, подпись даты, обложки других публикаций.
- Время просмотра: общее время в секундах, среднее время, процент полного просмотра, новые подписчики.
- Графики: точки просмотров, удержания и лайков; метки осей; описание лайков.
- Аудитория: всего зрителей, источники, группы зрителей, пол, возраст, места. В таблицах редактируются подписи, проценты и наличие стрелки.

Просмотры задаются один раз. И верхний счётчик, и карточка метрик используют stats[0]. Длительность задаётся один раз и применяется к подписи, обоим ползункам и расчёту среднего процента просмотра. Количество точек графика не задаёт его длительность. Горизонтальная шкала просмотров соответствует числу часов, вертикальная шкала учитывает введённые значения и метки. Суммарное время и среднее время — отдельные показатели, не повторы длительности.

Применение: изменить поля → Сохранить → Перейти к макету. Предпросмотр по ссылке всегда показывает сохранённую версию. Скачать JS выгружает текущие значения формы; кнопка не сохраняет их автоматически. При уходе со страницы с изменениями браузер предупреждает об их потере.

Архитектура:
- server/models/StatProject.js: коллекция stat_projects, один документ на проект; конфигурация, связь с видео, ревизия и даты.
- server/services/statProjectData.js: общая для API и формы проверка/генерация DATA. Никакой eval для данных из базы или запросов.
- server/data/stat-project-defaults.js: начальные значения.
- server/data/tt-stat/engine.js: общий код рендера без зашитых показателей проекта.
- src/assets/tt-stat/index.html и style.css: HTML/CSS шаблон внутри изолированного iframe.

JS собирается из DATA и engine по запросу, а не хранится второй копией в проекте. Ручной JS из прежнего редактора video_scripts сохраняется отдельно; новый проект не удаляет и не импортирует его автоматически. Для проекта меняйте поля на его странице и используйте её кнопку «Скачать JS».

Удаление проекта удаляет запись со всеми параметрами и делает его ID/ссылку недействительными. Видео, комментарии и прежние ручные JS не удаляются. Следующее открытие «Проект и параметры» создаст новый ID. MongoDB сможет повторно использовать освободившееся место; размер выделенного сервером хранилища не обязан сразу уменьшаться.

Все API проекта и предпросмотр требуют входа. Изменения формы не правят исходную статистику видео в кабинете. Конкурирующее сохранение с устаревшей ревизией возвращает 409.

Проверки: npm run build; из server — node tests/stat-projects.js. Тест использует отдельную временную базу cxsp_<uuid> и удаляет только созданные в ней коллекции stat_projects/videos. Проверяет расчёты, генерацию JS, авторизацию, повторное создание, сохранение, конфликт версий, удаление ID и сохранность других данных.

Для запуска новых страниц обновите клиент и API сервера. На Vercel добавлены rewrites для /projects/:id и /projects/:id/preview. Автоматическая публикация и коммит в этой задаче не выполнялись.
